# 桌面執行

進行連續桌面操作、處理焦點／定位失效或權限提升時，讀 [桌面控制協定](desktop-control.md)，並按需要執行動作前檢查器。

1. 取得目前視窗清單，定位文件與程序；不要沿用跨執行的舊 window-id。
2. 還原最小化視窗。需使用者可見操作時，把正確視窗帶到前景。
3. 先檢查模態對話框。主視窗截圖可能看不到範本或首次啟動提示。
4. 取得新 accessibility snapshot，優先唯一控制項。Windows PowerShell 的 @ref 與 x,y 座標加引號。
5. 單次操作後核對結果。文字貼上前確認插入點，排除尾端換行造成的空白項目。
6. 若狀態不明，重新讀畫面。不能因工具 ok=true 就判定文字已填對。
7. 另存檔時明確選格式，副檔名不能替代格式設定。
   Windows 原生另存新檔欄位使用反斜線完整路徑；若出現無效檔名，讀取錯誤對話框再修正，不反覆點存檔。
8. 每頁／工作表／文件區段檢查，再儲存和重開。

agent-desktop 使用時先讀其 skills get desktop、skills get platform 與子命令 --help。
若工具要求互動授權或沙箱提升，遵守該環境的權限機制。
檔案被占用時先儲存並使用受支援的唯讀存取方式；不要強制終止使用者應用。
PowerShell 驗收設定 `$ErrorActionPreference = 'Stop'`，外部命令另檢查結束碼與 JSON ok；只有存在、讀取、內容比對全部成功後才輸出 PASS。

對「在 LibreOffice 裡製作 PPT 並讓我看」的驗收，需要實際在 Impress 新增、編輯及儲存頁面。用桌面工具啟動產生器只證明程序可啟動。
