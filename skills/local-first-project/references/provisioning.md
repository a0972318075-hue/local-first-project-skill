# 補足決策

| 狀況 | 下一步 | 驗證 |
|---|---|---|
| 已裝且可用 | 沿用現有環境 | 最小任務 |
| 已裝但 PATH 未設定 | 使用已驗證絕對路徑或局部環境設定 | 版本與啟動 |
| 缺外掛或套件 | 僅補必要部分，先核對相容性 | 功能測試 |
| 免費工具確實缺少 | 核對官方來源、授權、版本、架構與現有授權，執行最小安裝 | 啟動、最小任務、重開 |
| 指定工具需付費 | 查現有授權或可合法使用方案，必要時請使用者決定 | 授權與功能 |
| 受管理裝置拒絕 | 記錄拒絕原因與允許的替代路徑 | 不繞過管理限制 |
| 下載或安裝中斷 | 查程序、檔案、安裝紀錄，確認是否已完成或部分完成 | 再決定重試／恢復 |
| 原工具不可用 | 提出符合任務的替代方案；指定工具的替換須同意 | 原驗收條件仍成立 |

優先官方套件管理器識別碼或官方簽署安裝包。GitHub 僅在確認為發布者官方儲存庫時作取得來源。
雜湊只有在來自可信獨立發布資訊時才可驗證下載真實性；自行計算雜湊僅能識別檔案。
不要執行未知 curl-pipe-shell、破解工具或停用防護措施。
先確認版本、scope、來源、預期副作用與恢復方式，安裝後記錄實際結果。
本技能提供代理決策流程，沒有通用的一鍵安裝器。每種軟體使用當前官方支援的安裝方式。
